# NITSON · Developer Portfolio

![Portfolio Preview](https://via.placeholder.com/800x400?text=NITSON+Portfolio)

A modern, cinematic, and futuristic developer portfolio built with **pure HTML, CSS, and JavaScript**. This portfolio showcases my work as a game and web developer with a dark, premium aesthetic and smooth animations.

## ✨ Features

- **Dark/Light Mode** with localStorage persistence
- **Bilingual Support** (English & Persian) with RTL support
- **Cinematic Slider** with auto-play, touch swipe, and keyboard navigation
- **Typewriter Effect** for about section text
- **Animated Starfield Background** (lightweight canvas)
- **Custom Cursor** with interactive hover effects (desktop only)
- **Smooth Scroll** navigation
- **Scroll Reveal Animations** using IntersectionObserver
- **Responsive Design** (Mobile First)
- **Glassmorphism & Neon Glow** effects
- **Performance Optimized** (vanilla JS, no heavy libraries)

## 🛠️ Technologies Used

- **HTML5** - Semantic structure
- **CSS3** - Custom properties, animations, responsive design
- **Vanilla JavaScript** - Interactions, animations, theming
- **Font Awesome** - Icons
- **Devicon** - Technology logos
